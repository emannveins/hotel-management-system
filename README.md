# Hotel Management System

## Descrizione del progetto

Il progetto tratta un sistema backend REST per la gestione di un hotel/albergo, Il sistema permette di amministrare camere, 
clienti e prenotazioni, verificando la disponibilità delle camere.

funzionalita del progetto:

1. Gestire i clienti: registrare clienti, visualizzarli e cercarli.
2. Gestire le camere: inserire camere, specificare tipologia, prezzo e stato.
3. Gestire le prenotazioni: creare, visualizzare, modificare e cancellare prenotazioni.
4. Controllare la disponibilità: verificare quali camere sono libere in un determinato periodo.
5. Calcolare i prezzi: calcolare automaticamente il costo del soggiorno in base alle notti.
6. Gestire check-in e check-out: registrare l'arrivo e la partenza degli ospiti.
